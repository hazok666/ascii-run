# ASCII RUN

An old-school arcade runner where everything is drawn with text characters, black and white only.
Auto-run, two buttons: JUMP (left half) and THROW (right half). Find the letters, reach the treasure.

**Play:** https://hazok666.github.io/ascii-run/ (landscape, works best added to the home screen)

- One self-contained `index.html`: game, embedded font (JetBrains Mono, OFL 1.1), chiptune music synthesized in code,
  and the radio voice (pre-rendered with meSpeak / eSpeak).
- Game design & art direction: Eric. Concepts & ideas: Emmylou & Edward. Code: Claude (Anthropic).
